# Minecraft UI textures

The block and music-disc PNGs in minecraft/ are original Minecraft Java Edition
textures extracted from the locally installed 26.2 client JAR. Original artwork:
Mojang Studios / Microsoft. The application loads these small UI assets locally.

Instrument icons use representative note-block base blocks; Harp uses Note Block.
Copper oxidation stages identify the four trumpet instruments introduced in 26.1:
https://www.minecraft.net/en-us/article/minecraft-java-edition-26-1
